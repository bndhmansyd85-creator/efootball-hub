eFootball Hub Auto Backend
==========================
هذا الخادم يفحص صفحات أخبار KONAMI الرسمية ويحتفظ بآخر النتائج في الذاكرة.
الفحص التلقائي: كل 15 دقيقة أثناء تشغيل الخادم.

التشغيل:
1) ثبّت Node.js 18 أو أحدث.
2) داخل المجلد نفّذ: npm install
3) شغّل: npm start
4) افتح: /api/news
5) من التطبيق استخدم رابط الخادم + /api/news

مهم:
- يجب إبقاء الخادم مستضافًا ويعمل 24/7 حتى يستمر الفحص.
- هذا ليس API رسميًا من KONAMI؛ هو جامع معلومات من صفحاتها العامة.
- يجب احترام شروط استخدام الموقع وسياسات الاستضافة.
- الإشعارات الفورية للهاتف تحتاج خدمة Push منفصلة في مرحلة لاحقة.
